# 高性价比人生指南 · 抖音视频工程

把开源书《高性价比人生指南》（34 章）做成 34 集竖屏科普短视频的完整工程。画面全部由代码逐帧绘制，配乐和音效由代码合成，一条命令出片。

第 1 集《不要早死》已发布，可作为标杆：`episodes/ep01/`。

## 目录

```
build.sh            一条命令出片
setup.sh            首次安装依赖
engine/             通用引擎（所有集共用）
  index.html        渲染页面（加载 stage.js + 本集 scenes.js）
  stage.js          画面系统：配色、字体、图标库、编号/图标/标题/成本标签、字幕、心电图、转场
  template_scenes.js 新一集默认场景（不写定制动画也能出片）
  timeline.py       逐句配音 → timeline.json（画面/字幕/混音唯一时间线）
  align.py / asr.py 整段配音按句切分，并用离线语音识别逐句核对读音
  render.py         逐帧渲染：检查帧 / 整片 / 封面帧 / 音效事件
  mix.py            配乐（D 小调铺底 + 心跳）+ 程序化音效 + 人声压缩闪避
  mux.sh            合成成片，两遍响度标准化 −14 LUFS
  cover.py          竖版封面
  deliver.py        SRT 字幕 + ≤9.8MB 发布版 + 发布文案
  new_episode.py    从原书章节生成一集骨架
  fonts/            思源黑体/宋体（简体）+ Inter，保证任何电脑上字形一致
book/               原书 34 章（CC BY 4.0）
episodes/epNN/      每集一个文件夹
  script.json       口播稿、字幕、条目、封面、发布文案、声音设计
  scenes.js         本集场景动画
  候选条目.md        本章全部条目（按收益排序，✓ 为已选）
  FACTS.md          数据核对表（每个数字对应原书条目与论文出处）
  vo/take.mp3       整段配音（放进来即可）
  vo/口播稿.txt      拿去配音的文本
  out/              成片、发布版、封面、字幕、发布文案
```

## 首次使用

```sh
sh setup.sh
./build.sh ep01 stills 3 20 55     # 渲染几张检查帧，确认环境正常
```

## 做一集的流程

1. **选条目、写口播稿**：打开 `episodes/epNN/候选条目.md` 和 `script.json`。骨架里已自动挑了收益最高的 6 条，并用「说人话」生成草稿，`【待写】` 处需要补：钩子、回顾、总结、标题、封面标语。
   - 口播稿要口语化；给配音用的数字写成汉字（「百分之四十五」），`subs` 字幕里写阿拉伯数字。
   - 每个数字都要能在原书找到，写进 `FACTS.md`。
   - 可以直接对 Claude 说：「按 opus-video-studio 技能，把第 N 集口播稿写好」。
2. **配音**：把 `vo/口播稿.txt` 交给配音工具，导出整段音频存为 `vo/take.mp3`。
   - 默认音色：ElevenLabs「Brian - Deep, Resonant and Comforting」（vidIQ 里生成，约 14 积分/集）。
   - 也可以用剪映「文本朗读」的「舌尖解说」等音色，导出音频即可。
3. **出片**：`./build.sh epNN`。自动完成：按句切分并核对读音 → 时间线 → 混音 → 渲染（约 10 分钟）→ 合成 → 封面 → 发布版。
   - 读音核对报告：`vo/align_report.txt`（第三列 <0.9 的句子要人工听一下）。
4. **检查**：`./build.sh epNN stills 5 20 40 ...` 出联系表 `out/sheet.jpg`；看完整片 `out/EPNN_标题.mp4`。
5. **精修（可选）**：通用模板每条只是「标题 + 关键数字卡」。想达到第 1 集的水准，在 `scenes.js` 里给每条写专属数据动画（参考 `episodes/ep01/scenes.js`：柱状图收缩、圆环、小人矩阵、谣言盖章、楼道剖面、点阵）。
6. **发布**：抖音创作者中心 → 发布视频 → 上传 `out/*_发布版.mp4`（网页端上传限制 10MB 以内）→ 按 `out/发布文案.txt` 填标题、简介、话题 → 封面上传 `out/cover.jpg`（竖封面）→ 合集选「高性价比人生指南」→ 公开发布。

单步命令：`./build.sh epNN align | timeline | mix | stills [秒...] | render | mux | cover | deliver`

## 本地配音与配乐（2026-10-23 起）

用本机 `~/Documents/ChatGPT/kindle/audio-stack` 的模型，不花积分、不联网：

- **配音**：Qwen3-TTS 1.7B（MLX）。全系列一个旁白音色：先 `./build.sh voice-design` 生成 6 个候选（`voices/candidates/`），试听后 `./build.sh voice-pick <编号>` 定下来（存为 `voices/narrator.wav`，只做一次）。之后 `./build.sh epNN voice` 逐句生成到 `vo/lines/`，每句用 Qwen3-ASR 回听，相似度 < 0.92 或语速异常就换种子重试，最多 4 次。报告在 `vo/voice_report.txt`，带 ⚠️ 的句子要人工听。口播稿里的阿拉伯数字、百分号、单位、年份、时间、电话号码会自动转成读法，转换结果也写在报告里。改了口播稿再跑，只重做改过的句子；`--redo hook:0,belt:2` 强制重做指定句。
- **配乐**：ACE-Step 1.5 XL-SFT（MLX）。`./build.sh epNN music` 按本集时长生成纯音乐铺底 `out/bgm.wav`，`mix.py` 会用它替代代码合成的和弦铺底，心跳、音效、人声闪避照旧。`--cands 3` 出 3 个版本试听，`--use 2` 选定。`script.json` 里可加 `"music": {"caption": …, "bpm": 64, "key": "D minor", "seed": 7, "steps": 48}` 调风格，`"off": true` 回到代码合成；`"sound": {"bgm_gain": 2.2}` 调铺底相对心跳的音量。
- **全流程**：`./build.sh epNN` 没有 `vo/take.*` 时自动走本地配音，有就仍按原来的整段切分（第 1、2 集）。
- 原版 `build.sh`、`engine/mix.py` 备份为 `.bak`。

## 设计规范（全系列统一）

- 画幅 1080×1920，30fps；深色底 #0E0E10，奶白字 #F2EDE4；金色 #F2B544 = 重点/成本，红 #FF5232 = 危险，绿 #3DD68C = 改善。
- 字体：标题思源宋体 Black，正文思源黑体，数字 Inter Display。
- 抖音安全区：顶部 200px、底部 420px、右侧 160px 不放关键内容；字幕在 1300–1480px，数字与关键词金色高亮。
- 结构：前 3 秒钩子 → 每条「编号翻滚 + 图标飞入 + 大标题 + 数据动画 + 成本标签」→ 回顾打勾 → 下一集预告 → 出处与许可（停留 ≥3 秒）。
- 声音：人声比音乐高约 13–15dB；心跳贯穿；关键句前留一次安静；成片 −14 LUFS、真峰值 ≤ −1.5 dB。
- 禁用：粒子爆炸、光晕、RGB 分离、弹跳缓动、默认淡入淡出、胶片颗粒（纯色动画加颗粒会让文件暴涨）。

## 版面主题与运镜（2026-10-24 起）

- `engine/themes.js` 里有 12 套版面（橱窗暖光、干邑皮革、墨绿织带、风衣卡其、礼盒橙、知更蓝、象牙杂志、霓虹商场、克莱因蓝、鹦鹉绿编织、落日玻璃、晨雾灰粉），`script.json` 写 `"theme": "orange"` 或环境变量 `THEME=` 选用。每集出片前先把总览图（`episodes/ep04/out/themes/00_总览.jpg`）发给用户挑。
- 运镜：每段缓推/拉/横移、背景 0.4 倍视差、斜切光边转场+对焦、标题扫光、浮光微尘。
- 配乐动态：`sound.dynamics`（段落力度 / 句间接话 / 重音推送），`sound.duck` 调人声闪避深度。
- `RANGE=0:17.5` 只重渲一段 → `out/video_part.mp4`；发布版用 720p 两遍编码 250k 控制在 10MB 内。
