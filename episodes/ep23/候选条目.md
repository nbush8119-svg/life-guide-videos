# 第 23 集《学什么技能划算》候选条目（原书 23-学什么技能划算.md，共 25 条，按收益排序）

- [✓] 第1条｜收益大｜证据A｜不满 16 周岁没有「去打工」这个选项：招你的单位每月被罚 5000 元，肯招的都是黑工
  - 说人话：初中毕业一般 15 到 16 岁，正好卡在这条线上。不满 16 岁，除了文艺、体育单位的特招，单位招你就是违法，每用一名童工每月罚 5000 元。所以肯要你的，都是在违法用工的单位。真出了事，医药费和赔偿只能找这家单位要。
  - 成本：不花钱。花一分钟算一下自己多大。
- [✓] 第4条｜收益大｜证据A｜「读不起」先按政策算一遍：公办中职学费对农村和困难学生大多已免，助学金 2300 元，助学贷款每年最高 2 万
  - 说人话：公办中职里，农村学生、城市涉农专业学生和家庭困难学生已经免学费。中职和普通高中的助学金，2025 年春季起每年 2300 元。上了大学，助学金每年 3700 元，助学贷款每年最多能借 2 万。钱不够时，先把这几样算一遍，再决定要不要退学去打工。
  - 成本：不花钱。开学前去学校的学生资助管理机构问一次，交一次材料。
- [✓] 第7条｜收益大｜证据A｜先记住基准线：多受一年教育，全球平均的私人回报（落到自己收入上的那部分）约为每年 9%
  - 说人话：按全世界平均算，多读一年书，个人收入每年高约 9%，女性的回报一直高于男性。这个数说的是正规上学，报一个班不能直接套。拿它当尺子：一个课程要你花 3 万元和半年，就问它带来的收入变化抵不抵多读一年书。
  - 成本：不花钱。把这个数记住，当成衡量各种「学点东西」方案的尺子。
- [✓] 第10条｜收益大｜证据B｜挑技能时优先看「要不要动手、要不要现场判断」，这类最难被自动化顶掉
  - 说人话：按美国的估算，约 47% 的岗位有较高风险被计算机接手，后来按具体任务估的比例低得多。机器难过的坎有三样：手上的灵巧劲、想出新东西、跟人打交道。所以要到现场、环境不标准、得临场判断的活更难被顶掉，流程固定、主要处理信息的岗位风险最高。
  - 成本：不花钱。选之前先按这个维度把想学的活过一遍。
- [✓] 第14条｜收益大｜证据A｜学完先合上书自己考一遍，别回头重读
  - 说人话：比起读完再读一遍，合上书考自己一遍效果更好。课堂上加了小测验，成绩提高属于中等幅度。给十种常用学法排名时，自测排在最高一档。读完一节先默写要点，再翻回去对。
  - 成本：不花钱，总时间也不用增加。把原来用来重读的那段时间，改成合上书默写或者做题。难在自测当场就把没记住的暴露出来，感觉比重读难受。
- [✓] 第15条｜收益大｜证据A｜把同样的时间摊到几天，别一次学完
  - 说人话：同样的时间，分几天学比一次学完记得牢。还有一条实用规律：你要记到多久以后，复习间隔就该拉多长。考得越远，间隔越长，但具体隔几天，研究没给通用的数。
  - 成本：不花钱，总时间也不变。变的只是排法：同样 3 小时，拆成三天各 1 小时。难在要提前几天开始，不能拖到最后一晚。
- [ ] 第24条｜收益大｜证据B｜本科毕业要不要接着读硕士：先算学费和少挣的两三年工资，再看自己读的专业多挣不多挣；已经上班的可以读非全日制，证书和全日制效力相同
  - 说人话：读硕士要花学费，还要少挣两三年工资，后者通常是大头。英国一项研究扣掉家庭和本科成绩的差别后，35 岁时读过硕士的女性只多挣约 2%，男性还少挣约 2%，不同专业差别很大。已经上班的可以读非全日制，证书效力和全日制一样，但领不到国家助学金。
  - 成本：不花钱。查一次招生简章和学费标准，再按手上的工作机会算一次账，大概一两个小时。
- [ ] 第25条｜收益大｜证据B｜硕士毕业要不要接着读博士：目标岗位明确要博士才读，读之前把心理负担也算进去
  - 说人话：同一项英国研究里，扣掉家庭和本科成绩的差别后，35 岁时博士比只读本科的女性多挣约 8%，男性反而少挣约 9%。读博的心理负担也重，各国博士生里约四分之一有明显的抑郁症状，约六分之一有明显的焦虑症状。所以先看目标工作是否非博士不招，再决定读不读。
  - 成本：不花钱。去目标单位的招聘公告里查一遍学历要求，再找两三个在读博士聊一次。
- [ ] 第3条｜收益中｜证据A｜判断「学历是不是贬值了」之前，先看全国的学历结构：每 10 万人里只有 15467 人有大学文化程度（2020 年普查，2025 年抽样推算约 19%）
  - 说人话：2020 年人口普查时，全国念到大专及以上的约占 15%。2025 年的抽样调查推算约 19%，五年里多了几个百分点。两次都是初中学历的人最多。15 岁以上的人平均只读了 9.91 年书，刚过初中毕业。所以初中学历在中国是人数最多的那一档，谈不上稀缺。
  - 成本：不花钱。看一眼下面的数字就行。
- [ ] 第5条｜收益中｜证据A｜没考上普高不等于路断了：中职有贯通招生和单独考试，事业单位技能岗位招聘还可以降学历要求
  - 说人话：2022 年的职业教育法写明：职业教育和普通教育地位同等重要。中职可以和高职贯通招生，高职还必须留出招生计划或者单独考试，专门招中职毕业生。用人单位也不得因为你是职业学校毕业就设门槛卡你。分数不够上普高，是换一条路，不是停在初中学历。
  - 成本：不花钱。填中考志愿之前，查一次本省的职教招生平台。
- [ ] 第6条｜收益中｜证据B｜把「读书还是打工」算成一道题：先去打工早挣的三年工资，对上接着读书换来的、往后几十年的年收入差
  - 说人话：先去打工，能早挣几年工资，但这笔钱只拿一次。接着读书，往后每年都比不读的多挣一些，要连着拿三四十年。所以要把这两笔钱放在一起比。中国城镇多读一年书，一年收入大约高 4.0% 到 10.2%，但这是 2001 年以前的数，只能看个大概。
  - 成本：不花钱。坐下来算一次，大概半小时。
- [ ] 第8条｜收益中｜证据A｜花钱考证之前，先查这张证在不在国家职业资格目录或人社部备案的评价机构名单里
  - 说人话：有些机构打着新职业、技能等级的名义乱办班、乱收费、滥发证，还有假冒权威机构的，人社部专门治理过。报名前按三步查：这个职业在不在国家职业资格目录、发证机构是不是人社部门备案的评价机构、证书编号能不能在官方平台查到。查不到的就别报。
  - 成本：不花钱。查一次，十几分钟。
- [ ] 第9条｜收益中｜证据A｜培训优先走政府补贴渠道，别一上来就自费报商业班
  - 说人话：2025 年到 2027 年底，国家计划办 3000 万人次以上的补贴培训。钱从就业补助资金、失业保险基金、企业职工教育经费等多个口子出。哪个工种越缺人、培训成本越高，补贴就越高。在职的先问单位，其余人先翻当地人社局的补贴目录，再决定学什么。
  - 成本：不花钱，或者能大幅减免。培训本身要占时间。难在忍住别一冲动就自费报班，先去查一遍补贴目录。
- [ ] 第11条｜收益中｜证据B｜学之前先确认这个技能有没有等级评价，等级能不能换成钱
  - 说人话：国家在推「新八级工」，要求企业把岗位工资和技能等级挂钩，表现突出的职工还能不看工龄资历直接认定等级。这是政策方向，各地各企业差别很大。有国家职业标准和等级通道的技能，往后才谈得上按等级涨薪，学之前先查一下有没有。
  - 成本：不花钱。查一次就行。
- [ ] 第12条｜收益中｜证据C｜别把「网上说工资高」当成缺人，去查当地的紧缺职业目录和补贴目录
  - 说人话：各地给哪个工种的培训补贴多，是按急需紧缺程度和培训成本定的，所以补贴额度能看出当地缺不缺人。网上说的「某工种月入多少」，多半是招聘平台的挂牌价或个人自述。你看到的多是挣到钱的人，也没算工时、通勤、职业病和淡旺季。
  - 成本：不花钱。查两份当地的文件。
- [ ] 第13条｜收益中｜证据C｜同样的钱和时间，优先选能直接上岗的短周期项目
  - 说人话：政策鼓励的是能短期就业的「短平快」培训，还有职业院校的微专业。挑项目只看一条：学完有没有一个具体岗位能投简历。学一年半载、结业还要「再积累经验」的，实际花掉的时间远超标价。开工前就写好退出条件：学到什么程度还没找到活就停。
  - 成本：要交短期课程的学费，钱不多。时间上要占一段。难在学到一半还没见效时，按说好的条件停下来。
- [ ] 第16条｜收益中｜证据A｜别把划重点、反复读、写摘要当成主要学法
  - 说人话：学生最常用的是划重点和反复读，可在十种常用学法的排名里，这两样都在最低一档。写摘要、关键词记忆法、给课文配图想象也在最低一档。它们不是完全没用，只是起作用的条件太窄，同样的时间换成自测更划算。
  - 成本：不花钱，反而省时间。难在这几样做起来最顺手，也最有「我在学习」的感觉。
- [ ] 第17条｜收益中｜证据A｜几种题型混着练，别一种连做二十道
  - 说人话：同一类题连做一大串，当场做得顺。把几类题打乱着练，长期效果更好，属于中等幅度。但这招挑材料：认画家风格这类看图的材料最有效，数学题小一些，背单词反而不如分块练。
  - 成本：不花钱。把练习册按题型顺序做改成打乱着做。难在混着练当场正确率更低，感觉像退步。
- [ ] 第19条｜收益中｜证据A｜要背的内容按将来的用法出题考自己，别原样背一遍就算完
  - 说人话：合上书考自己，好处不只停在背过的那几个字上。192 项对比、一万多人合起来算，它对换了题型的题、对应用题和推理题也管用，幅度中等偏小。但有两种情况效果最弱：把问法和答案对调，以及只在书上见过、从来没被考过的内容。
  - 成本：不花钱，也不多花时间。变的只是练法：把「原样背一遍」换成「按将来的用法出题考自己」。难在得先想清楚这些东西将来要怎么用。
- [ ] 第22条｜收益中｜证据A｜别找中介代评、别买论文代写、别在材料上造假：查实就撤销职称，记诚信档案 3 年
  - 说人话：用假材料、代写论文、剽窃成果拿到的职称，查实就撤销。失信记录要记 3 年，还进全国信用平台。申报时签的承诺书不实，3 年内不能再申报。人社部门还专门查处中介的虚假宣传、假冒评审和假证。
  - 成本：不花钱。难在忍住「花钱包过」的广告。
- [ ] 第2条｜收益小｜证据A（争议）｜把「读书有没有用」也放进死亡率账里：每多受一年教育，成人死亡风险降约 1.9%
  - 说人话：每多读一年书，成年后的死亡风险平均低约 1.9%。18 到 49 岁的人最明显，每多一年低约 2.9%，70 岁以上只低 0.8%。能一直读下去的人往往本来条件就好，这里面有多少是读书本身的作用，分不清。
  - 成本：不花钱。花的是多读那几年的时间和精力，学费那部分见本节第 4 条（中职学费和助学金）。难在要一直读下去，中间不放弃。
- [ ] 第18条｜收益小｜证据A｜别按「我是视觉型、他是听觉型」挑学法
  - 说人话：很多人相信每个人有自己的学习风格，比如视觉型、听觉型，按风格教才学得好。认真检验这件事的研究很少，几乎没有一项支持它，有几项的结果还正好相反。人确实各有偏好，但没有证据说按偏好上课就学得更好，不用花钱做风格测评。
  - 成本：不花钱。只是不再按这个分类挑材料、挑课程，也不再花钱做风格测评。
- [ ] 第20条｜收益小｜证据A｜评职称先弄清自己在哪个系列、哪一级，再按单位性质找申报渠道
  - 说人话：职称全国分 27 个系列，每个系列分初级、中级、高级。一般要一级一级往上报。在单位上班的，由单位审核、公示后往上报。在民营企业的，可以去职称申报受理服务点，或者找人才中介服务机构、行业协会申报。自由职业者报当地人社部门组织的评审。
  - 成本：不花钱。查一次本省当年的申报通知，半小时左右。
- [ ] 第21条｜收益小｜证据A｜会计这类初级、中级职称靠全国统考拿，先对照学历和工作年限去报名
  - 说人话：有些系列的初级、中级职称是考出来的，考过就算，不再另外评审。会计就是这样：助理会计师要高中以上学历，会计师要本科干满 4 年会计、大专满 5 年。已经拿到某些职业资格的，也可能直接算作有相应职称。
  - 成本：报名费按各省标准交。备考要占几个月的业余时间。
- [ ] 第23条｜收益小｜证据B｜拿到职称不等于涨工资：先问清单位是按岗位比例评聘，还是评了不一定聘
  - 说人话：职称是聘用、考核、晋升的依据，但评上和聘上是两回事。实行岗位管理的事业单位，一般在岗位比例内评。不实行岗位管理的单位可以评聘分开，评上了单位不一定给对应的岗位和工资。换单位、换地方后，职称可能要重新评或者确认。
  - 成本：不花钱。问一次单位人事部门就行。
