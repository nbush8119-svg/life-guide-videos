# 第 33 集《残疾之后怎么活》候选条目（原书 33-残疾之后怎么活.md，共 21 条，按收益排序）

- [✓] 第1条｜收益大｜证据B｜脊髓损伤之后突然剧烈头痛、出汗，先扶坐直、松开衣物，同时叫 120
  - 说人话：脊髓损伤的人，身体的报警线路断了一截。膀胱憋着、衣服勒着，本人可能没感觉，血压却会猛往上冲。信号是突然剧烈头痛和出汗。这时先把人扶坐直、松开勒紧的衣物、看是不是憋着尿，同时叫 120。
  - 成本：不花钱。三个动作，几十秒做完。
- [✓] 第2条｜收益大｜证据A｜脊髓损伤致残之后的头十年是自杀的高风险期，别当成「想开点」就行的事
  - 说人话：英国两家脊髓损伤中心的长期随访发现，这群人的自杀率是普通人的五倍。九成以上的自杀发生在受伤后的头十年。受伤原因本身就是自杀的人，风险还要高出一截。
  - 成本：不花钱。打一个电话，或者挂一次号。
- [✓] 第3条｜收益大｜证据A｜精神障碍住院以自愿为原则，只有两种情形可以不经本人同意
  - 说人话：家属或单位一句话，不能把一个人留在精神病院住院。法律只认两种情况，而且要先诊断为严重精神障碍：伤了自己或有这个危险，危害了别人或有这个危险。第一种要监护人同意才能收。第二种有异议的，三天内可以要求再次诊断，之后还能自己委托鉴定。
  - 成本：不花钱。把两条情形记住，需要时能说出口。
- [✓] 第4条｜收益大｜证据A｜长期照护家里残疾人的那个人，自己的身体要有人盯着
  - 说人话：照护者累垮不是矫情。一项美国研究跟踪了八百多位老人四年。一边照护失能的配偶、一边报告自己精神吃力的那批人，死亡风险比不照护的人高约六成。照护但不觉得吃力的人，没有出现这种升高。所以要盯的不是照护本身，是那份长期紧绷。
  - 成本：不花钱。把照护的活分出去一部分，自己去做一次体检。
- [✓] 第8条｜收益大｜证据A｜孩子不满 7 岁又有残疾或者孤独症的，去县级残联申请康复救助
  - 说人话：国家给 0 到 6 岁的残疾儿童和孤独症儿童建了一套康复救助制度，管手术、辅助器具和康复训练。救助对象先保困难家庭，地方财力允许的可以放宽年龄和家庭经济条件。救助按规定管到 6 岁，别拖到该上学了再说。机构要从残联的定点名单里挑。
  - 成本：不花钱。到县级残联交一次申请，然后在定点机构里选一家。
- [✓] 第16条｜收益大｜证据A｜康复在有康复医学科的正规机构做，强度听治疗师的，不是越猛越好（证据来自中风）
  - 说人话：中风后住进有组织照护的卒中单元，一年后还活着、还能住在家里的人更多。但也别自己加码，中风后 24 小时内练得更早、更勤、更多，三个月后的结果反而更差。练多少、什么时候练，听康复科和治疗师的。
  - 成本：住院康复每天几百元，自费的那部分因地而异。时间按月算。每天都要练，很枯燥。
- [ ] 第5条｜收益中｜证据B｜长期坐轮椅的，坐垫换成减压型，每天看一遍坐骨和尾骨
  - 说人话：养老院里用减压坐垫的老人，比用普通分段海绵坐垫的，坐骨那里的压疮明显更少，但把尾骨一起算就没看出差别。试验里所有人都先配了合身的轮椅，所以轮椅本身也要按人的尺寸配，别买个通用款就算了。
  - 成本：一个减压坐垫几百元到上千元。每天看一遍，一分钟。
- [ ] 第6条｜收益中｜证据A｜别买「能治好瘫痪、失明、耳聋」的疗法和器械
  - 说人话：广告法把话说死了。医疗、药品、医疗器械的广告，不许保证疗效，不许说治愈率和有效率，不许找代言人推荐、证明。所以「三个疗程站起来」「多少人已经康复」这类话本身就是违法广告，不用再研究它讲的原理。不是医疗器械的东西，连提治病都不允许。
  - 成本：不花钱，是省钱。难在家里人抱着希望，劝不住。
- [ ] 第7条｜收益中｜证据A｜残疾人证办下来之后，去县级残联把能申请的东西一次问全
  - 说人话：残疾人证本身不发钱，它是一把钥匙。接在它后面的是好几笔各自独立的待遇，每一笔都要自己去申请，不会自动上门。第一次去残联，就把清单上的项目一项项问过来，比来回跑几趟省事。
  - 成本：不花钱。去一趟县级残联，问一上午。后面要跑的部门不止一个。
- [ ] 第9条｜收益中｜证据B｜家里的坡道、扶手和浴室改造，可以向县级以上政府申请补贴
  - 说人话：《无障碍环境建设法》写了一条：县级以上政府应当支持、指导家庭无障碍设施改造。对符合条件的残疾人、老年人家庭，应当给予适当补贴。补多少、改哪几项由各地定，先去当地残联问。
  - 成本：申请不花钱。改造本身多数有补贴，自己可能还要补一部分。要跑残联和街道。
- [ ] 第10条｜收益中｜证据A｜找工作时主动说明自己持残疾人证，企业招你能抵掉一笔钱
  - 说人话：单位招残疾人的比例不得低于职工总数的 1.5%，各省再定。达不到就按差额人数交保障金，一个人头按本单位上年平均工资算，到 2027 年底打五折或九折，30 人以下的企业免交。所以招你是实打实省钱，面试时把持证说清楚。
  - 成本：不花钱。面试时多说一句话。难在开口。
- [ ] 第12条｜收益中｜证据A｜导盲犬可以带进公共场所和公共交通，盲人免费坐市内公交
  - 说人话：法律写明，公共场所和公共交通要为带导盲犬、导听犬、辅助犬的残疾人提供便利。盲人凭有效证件免费坐市内公交、地铁和渡船，残疾人可以免费带随身必备的辅助器具。被拦下来时把这两条说出来，不行就投诉。
  - 成本：不花钱。被拦下来时要开口引法条，可能要僵持一会儿。
- [ ] 第13条｜收益中｜证据A｜残疾人参加高考可以申请合理便利，用盲文卷的考试时间加一半
  - 说人话：残疾考生参加高考，可以申请盲文卷、大字卷、免外语听力、单独考场、带助听器和轮椅进场，考试时间也能延长。这些不会自动给，要按省里规定的时间交书面申请，附第二代以上的残疾人证。对结果不服，可以找省教育厅申请复核。
  - 成本：不花钱。要在省里规定的时间内交一次书面申请，还要到现场确认。
- [ ] 第14条｜收益中｜证据A｜残疾孩子申请入学，学校不得拒收；到不了校的由教育局安排送教上门
  - 说人话：幼儿园和各类学校，对符合条件的残疾孩子申请入学不得拒收，普通职业学校也一样。孩子需要专人护理、到不了学校的，由县教育局安排送教上门或远程上课，照样有学籍。入学和转学先由教育局的专家委员会评估、提建议，不由学校一句话说了算。
  - 成本：不花钱。要交一次申请，可能要经过一次评估。学校推脱时得往上找教育局。
- [ ] 第15条｜收益中｜证据A｜右下肢或者双下肢没了也能考驾照，准驾车型叫 C5
  - 说人话：右下肢或双下肢没了、动不了，但能自己坐稳、上肢条件够的人，可以考残疾人专用的自动挡小车驾照，代号 C5。一只手掌缺失、另一只手够条件的也能申请。单眼视力障碍、听力障碍的人各有能考的车型。体检要去省里认定的专门医院做。
  - 成本：学费和普通驾照差不多，多数地方几千元。车要改装成手动操控。每三年查一次身体。
- [ ] 第17条｜收益中｜证据A｜听力下降就去配助听器，配它的理由是听得见，不是防痴呆
  - 说人话：「戴助听器能防痴呆」这个说法目前没有立住。一项近千人的三年试验，总体上没有做出差别。只有在本来认知下降风险就偏高的那部分人里看到了差别。所以配助听器的理由是当下听得见、能和人说话、过马路能听见车，不是为了几十年以后的脑子。
  - 成本：助听器几千到几万元，多数要自费。要验配，还要来回调试几次。
- [ ] 第18条｜收益中｜证据A｜说一个成年人「管不了自己的事」，要向法院申请认定，家属说了不算
  - 说人话：一个成年人是不是「无民事行为能力」或者「限制民事行为能力」，只有法院能认定。家属、单位、居委会都不能自己说了算。要由利害关系人或者有关组织向法院申请。反过来，智力或者精神健康恢复了，也可以申请认定他恢复行为能力。这道程序既是限制，也是保护。
  - 成本：向法院申请不交案件受理费。要做鉴定的，鉴定费另算，一般由申请人付。法律要求 30 天内审完，做鉴定会拖得更久。
- [ ] 第19条｜收益中｜证据A｜成年人的监护人按法定顺序定；被监护人伤了别人，由监护人赔
  - 说人话：成年人失去行为能力后，监护人按顺序来：配偶，父母和子女，其他近亲属，最后是经居委会等同意的其他人或组织。有争议由居委会、村委会或民政部门指定，不服找法院。清醒时可以书面指定将来的监护人。被监护人伤了别人，先用他自己的钱赔，不够的监护人补。
  - 成本：不花钱。有争议时要到居委会、村委会、民政部门或者法院去解决。
- [ ] 第20条｜收益中｜证据A｜因为残疾被拒招、不转正、少发钱，可以告，但先把过程成本算清
  - 说人话：法律禁止在招用、转正、晋级、评职称、报酬、社保上歧视残疾人。你可以向主管部门投诉，也可以去法院告。但打赢了官司，对方也不替你出律师费。所以先投诉，同时申请法律援助，再考虑打官司。
  - 成本：律师费几千到几万元，自己出。一审普通程序按规定 6 个月内审完，可以延长。证据要自己保存。
- [ ] 第21条｜收益中｜证据B｜脊髓损伤后尿不出来的，排尿方式和医生一起定，别长期插着尿管不管，终身定期查肾和膀胱
  - 说人话：脊髓损伤后尿不出来，就要靠导尿这类办法排空膀胱。英国跟了七十年的数据里，一成多的死因在泌尿生殖系统。长期插着尿管的人，出并发症的比例比定时自己导尿的高约一倍。不管用哪种办法，肾和膀胱都要终身定期查。
  - 成本：自己定时导尿，一天要做四到六次，每次几分钟，导尿管要一直买。复查每一到两年一次，要挂泌尿科或者康复科。难在天天做、几十年不能断。
- [ ] 第11条｜收益小｜证据A｜残疾人的个人所得税可以减征，减多少打电话问省税务局
  - 说人话：个人所得税法写着，残疾人的所得可以减征个税。但是减多少、减多久，法律交给了省级政府定，所以各省不一样。办法是打 12366 纳税服务热线问本省税务局，或者在个人所得税 App 里找减免事项。
  - 成本：不花钱。申报时勾一项，或者交一次备案材料。
